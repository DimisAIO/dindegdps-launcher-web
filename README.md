## Translation
Join DindeGDPS Plus at https://discord.gg/sVcFBddjfj and give your language.
Make a fork of the launcher.
Inside the languages folder, create a a file containing the ISO code of your language https://en.wikipedia.org/wiki/ISO_3166-1_alpha-2#Officially_assigned_code_elements
Make a pull request and I'll review it!
